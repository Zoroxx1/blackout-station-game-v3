# Changelog
## 1.0.0
- Seeded generator (7x4 rooms, spanning tree + loops, hatches, keycards, 3 terminals, 1-2 wall generators, pod) with validation and a 1000-level test.
- Full 3D world with PBR textures, 8 wall panel designs, dead ceiling fixtures, emergency lights, decals, signs, props, instancing, room culling, light budget.
- Animated doors/hatches, lockers, terminals, wall generators, escape pod.
- First-person gloved hands with flashlight, scanner, decoy, keycards.
- Rigged procedural monster, blind-hunter AI, 4 escalation stages, caught cinematic.
- Audio: synthesized bank, buses, HRTF, occlusion, convolution reverb, ducking, adaptive layers, subtitles, debug panel.
- Post-processing (bloom, GTAO on High, grain, vignette, CA, grade, panic, glitch), UI screens, key rebinding, touch controls, saves, hard mode, optional Spring Boot backend.
